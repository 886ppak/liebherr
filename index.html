MYSLEWER v2.20

Myslewer — Beta Trial

This is a beta build of Myslewer, a reference tool for the fleet's LRT/LTM/LTR mobile cranes — rope retensioning, hook block selection, outrigger support positioning, counterweight combinations, and driving-with-equipment-in-place figures, all in one offline-capable app.

This trial build is time-limited and will lock itself out on —. That's expected — it's not a bug. This build is separate from the production tool, so nothing here affects anyone else's copy.

Every figure in this app is a reference only — always cross-check against the current OEM documentation before acting on it. If you spot something wrong, missing, or confusing in any tab, that's exactly the kind of feedback this trial is for.

What Each Tab Does
Reeving Plans
Pick a crane, boom/head configuration, and number of parts of line to pull up the matching reeving diagram — how the rope threads through the sheaves for that lift.
CWT Combinations
Look up valid counterweight stack combinations for a crane, including how each slab/segment builds up to a known total.
Driving with Equipment in Place
For travelling with the boom and counterweight still rigged: hook block allowance, boom angle range, support width, and max axle loads for the selected configuration.
Minimum Hook Block Weights
Works out the minimum hook block weight needed to keep the rope under tension for a given crane and rigging setup.
Outrigger Support Positioning
Visual site plan for outrigger/support leg placement, with reference frames for all four legs.
Rope Retentioning
Winch and rigging setup calculator for re-tensioning rope on the drum.

Site Rules & Rigging Weight
Both the printed chart capacity AND the target load you enter are for reference only until rigging weight is accounted for — per the OEM load chart manual ("40.02 Basic information"), the weight of load lifting equipment and fastening equipment must be deducted from the chart's capacity, since it hangs from the boom tip before your actual load is even attached. Selecting a block here (and Winch 2's, if fitted) applies that deduction automatically.
