Chain Shortening Calculator
Result
Pitch per link is looked up from chain diameter (8/10/13/16/19/22/26mm), same table as the reference shortening calculator. Links to remove is rounded to the nearest whole link, so the actual shortened amount can land a few mm off the target — that's the "Difference from Target" figure below. "Top Down" is the same measurement this tool has always used (current minus desired length); where the total chain length is known, the same physical cut point is also given as "Bottom Up" — whichever direction is fewer links is marked quicker to count. "Two Legs (Match One)" only reproduces the reference lengths' relative difference, not their absolute values — it leaves the longer leg at full stock length and shortens the other leg by the gap between the two references, which keeps the same relative pick geometry with a shallower sling angle (since both legs are now longer overall). That trade-off suits jobs with spare headroom (e.g. loading a flat deck) — cross-check it still picks flat for the actual job before relying on it, and always cross-check against the chain's own data plate/certification before cutting.

Side clearance assumes the crane is parked with its centerline parallel to whatever it needs to clear (wall, stockpile, fence, etc.) — the true worst case, since at that parking angle the swing radius becomes pure sideways distance. Park at an angle to the structure and the real clearance is larger than shown here. Rear clearance assumes the crane is backed square up to whatever sits directly behind it, measured from the rear of the carrier chassis (or the tool box's own rear face, once fitted, if the checkbox above is ticked) straight back to each radius point. Carrier width is this fleet's standard 525/80 R25 tyre (see the crane operating instructions, chapter 1.03, for other tyre options) except where noted.
