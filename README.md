# liebherr
Liebherr Fleet Operations Suite is an offline PWA for crane operators, riggers, and lift planners. ​Rope Retention: Calculates line pull, min reeving, tension weight, and cheek plate configurations. ​Hook Block Calc: Recommends optimal blocks. ​CAD Mat Positioner: Visualizes outrigger shift angles and stationary mats.
